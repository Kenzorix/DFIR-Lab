# Evidence Hashing
## Overview
Evidence hashing is the process of generating a unique digital fingerprint of a file or forensic image to verify its integrity.
## What I Learned
- Purpose of hashing in digital forensics
- SHA-256 hashing
- MD5 hashing
- Verifying forensic image integrity
- Comparing hashes before and after evidence handling
- Maintaining evidence integrity
## Tools Used
-windows powershell
- sha256sum
- FTK Imager
## Practical Exercise
Generated a SHA-256 hash for forensic evidence and documented the hash value for integrity verification.
## Key Concept
If the hash value changes, the evidence has been modified or compromised.
