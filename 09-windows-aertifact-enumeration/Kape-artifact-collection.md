## 1. Artifact Collection with KAPE
KAPE (Kroll Artifact Parser and Extractor) was used as the initial artifact collection tool in this investigation.

The purpose of this stage was to collect relevant Windows forensic artifacts and prepare them for further examination using forensic analysis tools.

### Collection Process
1. Launched KAPE in the Windows analysis environment.
2. Selected relevant Windows artifact targets.
3. Configured the destination for the collected artifacts.
4. Executed the collection process.
5. Verified the collected artifacts before proceeding with analysis.

The collected artifacts were then examined and parsed using additional forensic tools to identify evidence relevant to the investigation.

### Forensic Significance
Targeted artifact collection allows investigators to efficiently gather Windows artifacts that may contain evidence of user activity, filesystem interaction, and program execution.
