# Windows Artifact Enumeration

## Overview
This lab documents a hands-on Windows forensic artifact investigation performed to identify and interpret evidence of user activity, file and folder access, and program execution.
The investigation involved the collection, extraction, parsing, and examination of multiple Windows forensic artifacts using different forensic tools.
The workflow began with artifact collection and continued through artifact parsing and analysis, with findings documented throughout the investigation.

## Investigation Objectives

- Collect relevant Windows forensic artifacts.
- Examine Windows artifacts associated with user activity.
- Identify evidence of accessed files, folders, and directories.
- Investigate artifacts that can provide evidence of program execution.
- Understand the forensic value of Windows Registry and filesystem artifacts.
- Practice using forensic tools to parse and interpret Windows artifacts.
- Document findings from a practical DFIR investigation.

## Investigation Workflow
Artifact Collection → Artifact Extraction → Artifact Parsing → Artifact Examination → Findings → Documentation
