# Deleted File Recovery
## Overview
Deleted file recovery is the process of attempting to recover files that have been deleted from a storage device but whose underlying data may still remain available.
## What I Learned
- What happens when a file is deleted
- Difference between deletion and overwriting
- How deleted data can remain on storage
- Why recovery becomes difficult after data is overwritten
- Examining deleted files during forensic investigations
## Practical Exercise
I created a test file, deleted it, and examined the evidence using FTK Imager to understand how deleted files can be identified during forensic examination.
## Key Concept
Deleting a file does not necessarily mean that its underlying data is immediately destroyed. The storage space may become available for reuse, and recovery may be possible until the relevant data is overwritten.
