# Memory Acquisition
## Overview
Memory acquisition is the process of capturing the contents of a system's volatile memory (RAM) for forensic investigation.
## What I Learned
- Purpose of memory acquisition
- Volatile vs non-volatile evidence
- RAM acquisition
- Memory image creation
- Hashing memory images
- Preserving the integrity of captured memory evidence
- Documenting memory acquisition
## Evidence
A memory image was captured for forensic analysis and its SHA-256 hash was calculated to verify integrity.
## Tools Used
- Memory acquisition tool
- SHA-256
- FTK Imager
## Key Concept
RAM is volatile evidence. Its contents can change or disappear when a system is powered off, so memory acquisition should be performed carefully and documented properly.
