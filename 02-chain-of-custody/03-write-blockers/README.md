# Write Blockers
## Overview
A write blocker is a hardware or software mechanism used in digital forensics to prevent data from being modified on the original evidence during examination.
## Purpose
Write blockers help preserve the integrity of the original evidence by allowing forensic investigators to read data without writing changes back to the evidence source.

virtual Suspect HDD → Write Blocker → Forensic Analyst
