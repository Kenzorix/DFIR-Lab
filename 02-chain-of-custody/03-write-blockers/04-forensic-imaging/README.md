# Forensic Imaging
## Overview
Forensic imaging is the process of creating a bit-by-bit copy of digital storage media for forensic examination while preserving the original evidence.
## What I Learned
- Purpose of forensic imaging
- Evidence acquisition
- Forensic image formats
- E01
- RAW/DD
- AFF
- SMART
- Evidence metadata
- Preservation of the original evidence
## Practical Work
I created and worked with a virtual forensic evidence drive and examined the resulting evidence using FTK Imager.
### Evidence
- Evidence identifier: HDD-001
- Evidence type: Virtual hard drive
- File system examined: NTFS
- Tool used: FTK Imager
